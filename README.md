# yanyanvv.github.io

Personal profile page for Yanyan Wang, AI strategist and writer of FutureTech with Yanyan.

Live at **https://yanyanvv.github.io/**

## What is here

| File | Purpose |
| --- | --- |
| `index.html` | The whole page. Static HTML and CSS, no build step, no JavaScript. |
| `assets/` | Avatar, newsletter logo, favicons, and the social share image. |
| `robots.txt` | Opens the site to search engines and AI crawlers. Points to the sitemap. |
| `sitemap.xml` | One entry for the home page. |
| `llms.txt` | Plain-text summary of the site for AI assistants. |
| `404.html` | Fallback page for unknown URLs. |

## Editing

Change `index.html` and push to `main`. GitHub Pages redeploys in about a minute.

When the page content changes, also update:

- the `description` meta tag and the matching Open Graph and Twitter descriptions
- the JSON-LD block at the bottom of `<head>`
- `llms.txt`
- `<lastmod>` in `sitemap.xml` and the date in the page footer
